# LLM API Keys for llm.nvim

This guide lists official API key pages and connection settings for common cloud model providers used with `llm.nvim`. Free quotas, model names, and policies change over time. Check the provider console for current pricing, regional availability, and limits before creating a key.

## Providers with Free Access

“Free” can mean three different things: an ongoing free tier, a router or model explicitly listed as free, or a one-time trial allowance. A trial is not the same as permanent free access. After a quota expires or runs out, the account may switch to paid usage. Enable a spending limit or a stop-when-free-quota-is-exhausted option where available.

| Provider | Free access and current scope | OpenAI-compatible endpoint | Main limitations |
| --- | --- | --- | --- |
| Google Gemini | Gemini API Free tier: selected models have free input and output tokens, including models listed on the current pricing page such as `gemini-2.5-flash` and `gemini-2.5-flash-lite` | `https://generativelanguage.googleapis.com/v1beta/openai` | Limits are applied per model and project; free-tier data may be used to improve Google products; advanced models may not be included |
| Groq | Free plan for development and testing; available models and quotas are shown on the account Limits page | `https://api.groq.com/openai/v1` | RPM, RPD, TPM, and TPD limits vary by model and account |
| SambaNova | SambaCloud Free tier; the current official table lists `DeepSeek-V3.1`, `Meta-Llama-3.3-70B-Instruct`, and `gpt-oss-120b`, with some preview models also available | `https://api.sambanova.ai/v1` | The documented example is 20 RPM, 20 RPD, and 200K TPD per model; accounts without a payment method use the Free tier |
| Cohere | A free trial key is issued after registration | `https://api.cohere.com/v2` | Chat is typically limited to 20 RPM; trial keys have a combined limit of 1,000 calls per month for other endpoints; intended for testing, not unlimited production use |
| OpenRouter | The `openrouter/free` router and several models with a `:free` suffix | `https://openrouter.ai/api/v1` | The router selects from available free models; model availability, context length, and limits can change |
| Cloudflare Workers AI | Workers Free includes 10,000 Neurons per day; paid plans also include a daily free allowance | Build the Workers AI URL with the account ID | The allowance resets daily in UTC; some frontier models require a paid plan or AI Gateway credits |
| NVIDIA NIM | `build.nvidia.com` offers free hosted inference trials for selected models | Use the endpoint and key generated by the Build page | Free access, models, concurrency, and rate limits are controlled by the current NVIDIA console state |
| SiliconFlow | Some models or new-account allowances may be free; verify the model page and account console | `https://api.siliconflow.com/v1` | Not all models are permanently free; prices, maximum usage, and promotions can change |
| Alibaba Cloud Model Studio / Qwen | New-user allowance: Beijing region only, issued per model, usually 1 million tokens per model, valid for 90 days | `https://dashscope.aliyuncs.com/compatible-mode/v1`, or a workspace-specific endpoint | Real-name verification is required; other regions usually do not receive this allowance; enable “stop when free quota is exhausted” to avoid accidental billing |

**Not permanent free access:** Cerebras currently offers a Free Trial of 5 USD after payment-method verification, expiring after 30 days. DeepSeek, OpenAI, Anthropic, Mistral, Kimi, and Zhipu should not be described as permanently free without a current official grant. OpenAI’s Free usage tier, where available, is an account-level usage limit rather than a free model; ChatGPT Pro/Business API credits are subscription benefits.

## Configure Keys

`llm.nvim` reads `LLM_KEY` by default. Put it in a shell configuration file such as `~/.zshrc`, then restart Neovim:

```sh
export LLM_KEY="paste-your-api-key-here"
```

Never put a real key in Lua configuration, commit it to Git, or print it in logs. When using multiple providers, set separate environment variables and select them with `fetch_key`:

```sh
export DEEPSEEK_API_KEY="..."
export OPENROUTER_API_KEY="..."
```

```lua
models = {
  {
    name = "DeepSeek",
    url = "https://api.deepseek.com/chat/completions",
    model = "deepseek-chat",
    api_type = "deepseek",
    fetch_key = function()
      return vim.env.DEEPSEEK_API_KEY
    end,
  },
  {
    name = "OpenRouter",
    url = "https://openrouter.ai/api/v1/chat/completions",
    model = "deepseek/deepseek-chat",
    api_type = "openai",
    fetch_key = function()
      return vim.env.OPENROUTER_API_KEY
    end,
  },
}
```

`fetch_key` can be a string or a function that returns a string. When using multiple models, set `fetch_key` explicitly for each model instead of relying on the shared `LLM_KEY`.

## Provider Example

Use this form for an OpenAI-compatible provider. Replace the URL and model with the values currently documented by the provider:

```lua
require("llm").setup({
  url = "https://api.siliconflow.com/v1/chat/completions",
  model = "Qwen/Qwen2.5-7B-Instruct",
  api_type = "openai",
  fetch_key = function()
    return vim.env.SILICONFLOW_API_KEY
  end,
})
```

Use the table above and the provider documentation for DeepSeek, Kimi, Zhipu, and other providers. OpenRouter model IDs normally use the `provider/model` form. Cloudflare Workers AI also needs an account ID; see the plugin’s Cloudflare example for the exact fields.

## Local Models

Ollama normally listens at `http://localhost:11434/api/chat`. Use `api_type = "ollama"`; when no key is needed, the plugin documentation requires `LLM_KEY` to be set to `NONE`:

```sh
export LLM_KEY="NONE"
```

```lua
require("llm").setup({
  url = "http://localhost:11434/api/chat",
  model = "qwen2.5-coder:7b",
  api_type = "ollama",
  fetch_key = "NONE",
})
```
